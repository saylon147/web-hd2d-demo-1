黄昏下西侧低角度主光把树冠和藤架的影子投向前庭，屋檐下主要靠门灯提亮。夜景从入口看，屋门和前窗成为最容易定位的部分；房屋近景下，两个门灯附近墙面的高光偏亮，灯罩细节较少，远处植被明显压暗。建议先判断小屋与庭院之间的明暗比例，再看门灯热点是否需要降低。点光没有局部投影，遮挡附近可能出现漏光；本阶段的窗户表现来自表面照明。

## 性能与测试

Chrome 157，Windows，生产构建。各组预热 30 帧，记录其后 90 个 requestAnimationFrame 间隔。日间、黄昏、夜景均为一次带阴影的场景绘制加最近邻呈现，Three.js 统计每帧 11 次绘制、377841 个三角形。六组均值约 16.7 ms，P95 约 16.8 ms。该测量受刷新率限制，无法分辨局部点光引起的 GPU 着色时间变化。

复现命令为 npm run build，然后 npm run test:browser -- tests/browser/h3-a.spec.ts。采集后使用同目录 contact_sheet.py 和 Pillow 重建对照图。Windows 本机使用 PLAYWRIGHT_BROWSER_PATH 指向 Chrome，NO_PROXY 包含 localhost 与 127.0.0.1。浏览器脚本检查日间基线、矩阵、开关引起的像素差异、URL 刷新复现，以及 Native 和 DOF 组合。模型与材质复用 H2，无新美术资产。当前状态为待人工视觉验收。

最终验证通过 npm run typecheck、npm run lint、npm run build、npm test（24 项）和 npm run test:browser（16 项）。构建保留 Vite 的主包超过 500 kB 提示。
