# G04-A1 — A2 前景基座单块 3D 小样 / Codex Handoff

状态：**批准进行单块可回退实验，不批准扩大范围**。依据：`review-gates/G04-A1-P0/REPORT.md` 的 S1 低位宽基座二维草案。Golden Reference V1 优先于补充概念图，P0 屏幕轮廓仅是设计意图，**不是世界坐标、实测边界或可直接挤出的网格**。

## 目标与范围
- 仅替换/遮挡 A2 front-wall 前景小窗口的可见碎石，验证“宽厚、低位、非对称、连续”的自然海岸主岩体能否成立。
- 四个设计角色：①宽厚主支撑体（最大）；②向后内收且有转折的顶面；③错位右肩及非对称凹口；④较小且靠近水线的前脚。避免四块等体积积木、重复台阶、薄板或垂直墙。
- 保持沙滩、楼梯、码头、房屋、原岛体、A1/A3/A4 以及导航/碰撞不变。A2 原资产必须可恢复；其他岩石仅作为背景，不改位置或材质。

## 先测量，后建模
1. 从实际地形、A2 及海平面获取世界坐标中的目标窗口、可见遮挡关系、上缘接触、侧端接口和水线；输出测量/定位证据。不得将 P0 像素线条当作真实几何边界。
2. 在同一坐标系制作**一个**低面数、闭合或具有明确遮挡终止面的 3D 候选。优先手工控制大形/少量截面与错位轮廓；允许 Blender 脚本辅助生成，但禁止把二维 SVG 简单等深挤出当成成品。若难以形成可信形体，报告障碍而不是自动转向大量碎石堆叠。
3. 用中性或极简分面色检查体积：正面、侧面和俯视都必须能看出前后厚度变化；顶面不应成为水平搁板；右肩凹口需有三维深度而非平面剪影；前脚在水线处自然收束，不应悬空或形成整齐底边。
4. 通过局部遮挡或实验层替换实现切换：baseline 原 A2 vs candidate 新大形。保持默认预设和旧 G01/G02/G03/G04 证据不变。避免改动正式 GLB 和现有 Tripo 文件。

## 视觉验收（必须同相机、同光照、同曝光、同裁剪）
- Golden：远景首先读成一块低位宽厚主岩体，而非一团同粒度碎石；房屋仍是视觉主角，沙滩/楼梯/码头保持清楚。
- Golden-close：可辨认主面、向后收的顶面、非对称右肩和较小前脚；不出现明显方砖感、整齐平板、浮贴或重复切面。
- Side：真实厚度和前后错位成立；与原崖的交接没有大缝、突兀竖切或悬浮。
- Below：水线、岩脚支撑和底面连续；不露出悬空平底或穿插。
- 附加一张无遮蔽的候选模型斜侧视图（中性材质），防止周边 Tripo 岩石掩盖几何缺陷。
- 每机位 baseline/candidate 并排，并附简短差异说明。若在 Golden 全景几乎不可辨，明确标注“视觉收益不足”，不得仅凭近景通过。

## 明确禁止
- 不做纹理烘焙、写实岩石表面细节、植被、泡沫、水体、全岛材质统一。
- 不扩展到 A1/A3/A4、右主崖、顶缘接缝联合改造。
- 不以测试通过替代视觉验收；不声称局部单块解决了整岛岩石风格问题。
- 不自动进入下一阶段，不批量尝试多个方案或长时间无界迭代。
