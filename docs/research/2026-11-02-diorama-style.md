# 微缩 3D 网页风格与模板调研

调研日期：2026-11-02。依据：用户提供的 27.3 秒、1920×1080 录屏，以及下文实际访问的公开产品、素材和教程页面。

## 结论

有现成的**场景模板、模块化模型包和教学项目**可以帮助制作这类效果。不过，尚无证据表明录屏这个作品，或小红书上同类作品，都来自同一套模板。复用提示词也可能带来相似构图，但当前没有作者提示词或工程可核实。

这类画面的检索名称是 **low-poly diorama / isometric diorama / cozy 3D scene**，中文可搜“低多边形微缩场景”“等距 3D 小世界”“治愈系 3D 网页”。它主要依靠形状、配色、构图和柔和阴影建立风格；我们的 Three.js 技术路线能够支持这个方向。

## 同质化与项目辨识度

用户反馈：同类作品反复采用相近尺寸的小场景，可能建立在共同基础上；同质化明显，看多了会失去吸引力。相似尺寸、底座与镜头是共用模板、教程或提示词的线索，但目前不足以确定来源。

后续研究应把制作效率与视觉辨识度分别评估。模块资产可用于提高效率，场景仍需要围绕本项目建立构图与空间关系。值得强化的方向包括：有特点的岛岸轮廓，海湾、崖壁、台阶与码头的联系，小屋与岩体及地下室的嵌合，具有地方感的生活细节，以及像素角色与手绘环境的融合。仅换建筑或配色，可能仍保留同一种模板观感。

这些是后续审图与方案选择的参考，不代表已批准改变现有场景或进入新里程碑。

## 对当前项目的建议

结合 `PLAN.md`、`ART_BIBLE.md`、`GOLDEN_REFERENCE_V1.md` 与 G03-P0 的问题，最值得借鉴的是以下四点：

1. **先统一大形与视觉频率。** 房屋、崖壁、石块和树冠应在默认相机下具有相近的细节尺度。高细节 Tripo 石块与简化崖面直接拼接，很容易显得来自不同作品；加碎石或噪声并不自动解决这个问题。
2. **把可重复资产组织成小套件。** 手工确定少量高质量的树、岩石、砖、瓦和台阶模块，再重复摆放。程序可以辅助摆放、变体与导出，关键轮廓仍需要美术判断。这个参考不能证明仅靠程序建模就能达到我们的 Golden Reference。
3. **记录可复用的配色与灯光预设。** 保留我们暖屋顶、奶油墙面、青绿海水的方向，测试降低饱和度、柔和接触阴影与明确主光。参考片偏浅色低多边形，Golden Reference 偏手绘层次，不能未经审图就把二者视为同一个美术目标。
4. **将动态效果分层加入。** 初期只需要轻微水纹或一条船的简单轨迹，主体先做到静态截图成立。网页 UI 可以参考它的留白；不因此扩展玩法。3D 环境平滑渲染，未来像素角色仍单独使用 nearest sampling。

如果下一步要验证，建议在一个独立、可撤回的小样里，只放“一段岩岸 + 一棵树 + 一小块水面”，对比现有材质方案与一套经过统一的模块资产。沿用固定相机、光照与截图条件，先判断形状与风格是否协调，再决定是否采购或扩大素材管线。不是直接换整座岛，也不是立即引入新渲染框架。
