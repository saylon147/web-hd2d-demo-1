# M2.2 视觉修复：短周期、逐关验收（Codex 指令）

基线：`codex/m2-2-coastal-assembly`。用户已审阅 `docs/m2.2-coastal-assembly/RESULTS.md` 的截图，指出上层岩石底面外露、岩块外挂、与台地不连续。**此文档替代“大任务一次跑到底”的执行方式，不代表批准现有视觉。**

## 总规则：一关一反馈

- 只执行用户明确批准的**当前关卡**。不要自动进入下一关、不要批量生成新 Tripo 资产、不要合并分支。
- 每关目标 15–30 分钟；达到 30 分钟仍无法解决，就停下提交当前诊断、阻塞原因和截图，不要静默连续运行数小时。
- 每关提交独立 commit；输出一张主视角及至少一张问题局部视角截图（固定相机/灯光/视口），附 3–5 行结论、涉及资产 ID/instance ID、改动文件和验证结果。截图保存 `docs/m2.2-coastal-assembly/review-gates/G0X/`；在回复中给出文件路径与本地可复现命令。
- 每关先做最小必要测试（配置/类型/对应浏览器测试），最终整体验收再跑全量测试。任何失败明确报告，不要伪称通过。
- 保持 M2.1 基线、房屋/地下室/楼梯/码头结构与碰撞不变；任何临时诊断可开关、默认关闭。参数化 placement，勿把坐标散落进渲染代码。

## G01 — 诊断底面外露（仅此关立即执行）

1. 读取 `public/assets/presets/coastal-assembly.json`、`src/world/coastal.ts` 和当前四个模型的实际世界变换。确定截图中“上层模型底露出”的**具体 instance ID**，不可先假定 A1/A4 或仅凭 AABB 推断。
2. 做可切换 debug overlay：实例 ID、世界轴、底部中心锚点、AABB、主要可见轮廓；标记与程序化岛体的空间交界。必要时以透明/线框地形、切面和侧视图辨别：朝向错误、底部悬空、岩体向外过伸、与原地形缺少接触、或者模型本身有开放面。
3. 输出固定主视角 + 正侧视 + 背/下方诊断截图，说明每块可疑实例的最低点、地形支撑位置、悬挑部分以及哪一面实际朝向镜头。射线/包围盒仅作辅助，不能替代视觉检查。
4. **G01 不允许修改岩石摆放、缩放、材质或原地形**。只交付诊断代码、截图、报告和 commit，然后停止等待用户确认 G02。

## G02 — 单实例修复（需用户批准）

只修 G01 定位的最明显一个实例。优先小幅平移/旋转/调整嵌入；保留尺寸和朝向记录。若简单变换无法同时解决顶部与底部，提出 Blender 裁切、局部地形过渡或局部几何变形的两种备选方案，**先请用户选，不要擅自改原始 GLB**。提供相同相机 before/after + 侧面截图，验证原结构保护后停止。

## G03 — 两实例接缝（需用户批准）

只处理 G02 已批准实例及相邻一块，验证悬空、交叠、重复纹理、崖顶断层和背面；记录 placement 参数变化；固定截图后停止。

## G04 — 材质/台地过渡（需用户批准）

仅对 G03 验收区域做颜色/粗糙度/法线与崖顶薄过渡带试验，提供「仅几何修复」「几何+材质」A/B；不修改全岛、不批量替换岩石。用户审图后再决定扩展。

## Codex 首条回复要求

确认目前所在分支和工作树状态；说明只执行 G01；列出预计输出截图路径与诊断命令。完成后**主动停下**，等待下一条明确指令。
