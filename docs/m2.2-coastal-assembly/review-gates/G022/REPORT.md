# G02.2 — front-shoulder / A4 局部主体替换

2026-10-30；基线 `4175fe3` / G02 C2。**仅交付最小渲染实验，等待人工审图。A4 的可见肩部增高、顶部距离缩短，但绿色接缝、两侧灰黄分层与岩层拉长仍可见；不宣称视觉通过。未执行材质统一、整段替换或 G03。**

**结构诊断与取舍。** 原 C2 A4 的 Y 范围1.852–2.770m，厚度约0.918m；局部原台地边缘 Y≈3.493–3.549m，高平台约3.8m。原厚度无法同时承担高崖主体和顶部连续性。首版保留厚度时出现明显绿色补片，故最终仅使用一个替代 A4 渲染副本，绕原底部锚点将 Y 高度乘 **1.8**，可见范围变为1.854–3.506m。C2 原实例 position=[7.95,1.85,3.35]、yaw=-8°、scale=[1.05,0.9,0.95]保留；替代体 scale=[1.05,1.62,0.95]。这是明显的非等比扩展，**不代表原形 A4 已能胜任完整连续崖壁**；纵向纹理/岩层比例改变是当前代价，没有追加石堆掩盖。

**局部替换。** 参数见 [coastal-g022.json](../../../../public/assets/presets/coastal-g022.json)。仅在 X=[6,9.3]、Y=[1.9,3.6]、Z=[1.9,4.95] 内，细分原陡崖渲染副本，并检查子面三角角点及中心是否落在 A4 替代体的上下表面之间；仅移除99个被覆盖子面，面积约3.881m²，保留9565个子面。覆盖判定是采样包络，不能当完整 Boolean/流形证明。未覆盖的灰壁继续作为封闭背衬；未隐藏整岛或整块崖壁。原地形顶面、沙滩、房屋等仍渲染，所有原地形 buffers 和命名查询对象保持不变。

顶部使用**一片**136三角形的台地过渡：沿4个原绿色边缘锚点（弧长约2.53m）精确起接，向外最大0.8m；19排接触采样，内缘保留原坐标，外缘埋入替代岩石顶面0.035m，两端收窄到原边缘。沿用原绿色台地材质引用，不调色、不添加纹理。两侧仍接回原崖壁，局部绿色肩部略显规整，存在岩石细节穿插，不能靠这片几何宣称自然地质过渡完成。
