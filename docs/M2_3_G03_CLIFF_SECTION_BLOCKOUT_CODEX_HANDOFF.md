## 1. 本轮范围：G03-A，仅做一段基础几何

- 选择现有 `front-shoulder` 所在的约 2–4m 海岸小段作为试验区。**优先选择能在 Golden 主视角清晰看到的区段**；如实际长度与地形拓扑不适配，报告选择的真实范围。
- 从**现有岛体的真实渲染几何/高度与边界**读取：崖顶边界曲线、相邻两端与原崖壁的接口、下部海岸脚/海平面附近轮廓。不得硬编码一块与岛体无关的平板或简单长方体。
- 使用 Blender Python **或** Three.js BufferGeometry 的确定性程序化方法，生成独立、可重复构建的 cliff-section 基础网格。优先选用现有工具链；不因使用 Blender 而引入新大型依赖。保留生成脚本、参数和可重复运行命令。
- 目标几何结构：顶部自然贴合原绿色台地；中段形成连续不规则崖壁；下部收向海岸脚/海面；两端渐变衔接现有崖壁。保留适度自然起伏，但避免明显规则的直立墙、平整楔块、重复台阶、悬空底面、薄片及洞口。
- **首版只用一种中性、无贴图的调试材质**，先判断轮廓和衔接是否成立。不得添加 Tripo 资产、岩石贴图、苔藓、植被或复杂 shader；不要将材质美化当成几何验收。
- 在实验变体中，可仅对试验区内旧崖壁的**渲染副本**做局部遮挡/替换，避免原崖壁与新崖壁两层叠加。保留原地形、原行走/碰撞/导航数据不变。禁止大范围隐藏整块岛体或破坏沙滩、楼梯、码头、房屋、地下室、崖顶。
- 原 A1–A4 GLB、所有 LOD/纹理、五个 placement 和 G01/G02/G021/G022 入口保持不变；新实验中可临时隐藏试验区的 A4 **可见副本**用于清楚展示新主体，但不能删除、覆盖或改变其源数据。默认正式场景不启用 G03-A。

## 2. 拆成小任务，严守停点

### G03-A0：几何提取与可行性检查（先做，15–30 分钟，独立 commit 并停下）

1. 找到当前岛体生成、顶面/侧壁/海岸脚的真实数据源；确认渲染和碰撞是否可隔离。
2. 提取试验段的崖顶、底部及两端接缝的世界坐标，输出可视化线框/标记和不超过一页的诊断说明。
3. 检查数据是否足够生成连续的网格；如原地形缺乏可用边界，提出最小可行提取算法，**不要猜测轮廓、不要开始建模**。
4. 固定 Golden、Golden-close、side、below 四机位输出边界标记图，确保我们能先审查选段和边界是否正确。
5. **完成 A0 后停止**。必须先获得人工批准才开始 A1。即使 A0 很快完成也不能自行继续。

2. 建立可切换的 `baseline` / `cliff-blockout` 实验入口。原默认 M2.2/G022 显示不变。
3. 同机位 Before/After 对比：Golden、Golden-close、side、below，附边界诊断视图；所有截图固定 camera/light/crop/DPR/LOD。
4. 只改这段可见海岸，不改碰撞与行走；不新增 Tripo 或贴图；不要进入下一步。
5. 独立 commit 并等待人工审图。

- 首要指标：Golden 主视角中，新崖壁与绿色台地、两端旧崖、海岸脚形成一体化轮廓；侧面/低视角无新露底、悬空、明显断口。
- 真实边界对齐优先于表面细节；不接受为遮丑而堆补丁。
- 所有实验独立、可切换、可回退；旧入口和默认画面不得改变。
- 运行相关 build/typecheck、lint、unit/browser smoke；报告无法运行的检查。截图必须真实来自本地运行结果，不得使用概念示意图替代。

- **每一子阶段 15–30 分钟反馈预算；超时先提交当前可复现证据并停下，不允许连续跑数小时。**
