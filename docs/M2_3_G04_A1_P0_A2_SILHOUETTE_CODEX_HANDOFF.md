## 目的

在投入 Blender/Three.js 造型之前，先验证 A2/front-wall 前景海岸基座的**大轮廓、主次体块、负空间和大切面**是否符合原始 Golden Reference V1。避免再次发生“几何/拓扑验证通过，但全景轮廓没有改善”的问题。

## 权威参考

1. `docs/references/golden-reference-v1.png`：整体构图、自然岸线、房屋主体比例、沙滩/楼梯/码头关系的**最高优先级**。
2. `docs/references/20261102195825_187_18.jpg`：四区结构及大面配色的补充解释；不是几何蓝图，不可机械照搬高耸柱状悬崖。
3. G04-A0 的 `mapping-golden.png`、`mapping-golden-close.png`、`candidate-plan.png`、`default-golden.png`：用于定位现有 A2 基座和可见范围。

## 唯一试验对象与范围

仅针对 01 海岸基座中 **A2/front-wall 正面可见主岩体**提出造型方案。G04-A0 给出的参考窗口 X=[8.2,11.2]、Z=[5.0,7.2]、Y=[0,2.35]m 只是候选包络，**不是允许直接替换的切割边界**。不要改动 A1/A3/A4、原岛体、房屋、台阶、码头、沙滩或默认预设。

## P0 具体交付（先画，不建）

1. 在**当前默认 Golden 未裁剪全景**上画一张清晰的 A2 局部造型覆盖图（overlay）。建议使用半透明暖色大面、明确外轮廓线和少量注释；保留房屋、台阶、码头、海面可辨识。
2. 在相同固定机位的 **Golden-close** 上画对应放大图。两图必须是**同一个造型方案**，不能各自画不同形状。
3. 用 **3–5 个可读的大/中体块**组织基座（数量是视觉指导，不是网格数量限制）；一个宽厚、接近水线的主支撑体，1–2 个不对称转折/凹口，少量次级岩块。避免均匀阶梯、平整长方板、垂直墙、重复方砖、球状碎石堆和细密岩纹。
4. 明确画出：左/右外轮廓、顶部内收趋势、主要受光面与背光面、与原岛体接触的位置、海平面/水下延续、保留的沙滩和楼梯附近负空间。**不要以颜色块代替真实大形**，但也不要为了颜色差异刻大量小凹凸。
5. 可选第二张**明显不同的**轮廓方案（例如较宽低缓 vs 较集中有机），但不得仅换颜色；优先交付一个判断明确的主方案，避免无意义多方案发散。
6. 用一个简短的 `REPORT.md` 解释：与 Golden V1 哪些关系一致、预期全景改善在哪里、哪些 Tripo 轮廓保留/舍弃、哪些接缝尚未解决、后续 3D 建模需要人工作出的决定。注明所有 overlay 为设计示意，不是测量几何或已实现模型。

## 视觉验收标准

- Golden 全景：新 A2 基座能被一眼辨认成**宽厚、连续、有机的岩体**，而不是碎岩团；但不能抢走房屋主体，也不能堵住沙滩/台阶/码头。
- Golden-close：看得清少量大面和非对称轮廓；保留原 Golden V1 的大小岩块自然层次，避免概念图那种整齐柱状崖。
- 造型与材质分离：大切面轮廓先成立，再讨论暖亮面/冷阴影；暂不设计高频纹理、苔藓、碎石和植被。
- 草案必须标明**只是屏幕空间的设计意图**；不要把 2D overlay 冒充 3D 模型或精确世界坐标。
- 保留前景 A2 与原地形的实际接缝、A3 海湾转角、03 右主崖、04 顶缘为后续联合设计问题；本轮不声称已解决。

## 禁止事项

- 不打开 Blender 进行正式建模；不生成/替换 GLB；不修改 Three.js 生产代码、Shader、mesh、碰撞、导航、相机、光照或场景默认。
- 不运行新的 Tripo 生成，不做材质或贴图迭代，不批量生成岩石。
- 不扩大到整个海岸或 02/03/04 的正式设计。
- 不直接进入 G04-A1 3D 小样。只有人工审过 P0 图后，才另行授权。
